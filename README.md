
# Vehicle Service Reminder and History System

## Description
This project checks when a vehicle needs servicing based on its kilometer reading.
It also stores service history, including date, work done, and extra repairs.

## Features
- Checks service due based on km
- Different intervals:
  - 2W → 2000 km
  - 4W → 5000 km
- Stores service details in a file
- Displays previous service history

## How to Run
1. Open the Python file
2. Run the program
3. Enter the required details

## Concepts Used
- Input and Output
- Conditional statements (if-else)
- Loops
- File handling
